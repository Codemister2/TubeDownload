# Kuudra Pilot V0.4 (Fabric 26.1.2)
Build targeting Minecraft 26.1.2, Fabric Loader 0.19.5, Fabric API 0.155.3+, Java 25.

IMPORTANT: This is a new real-dependency Gradle build, and the in-game supply/fishing/pearl behavior is EXPERIMENTAL. A successful Java build is not proof it completes Kuudra.

Install: remove any previous KuudraPilot JARs, place built jar in mods for the Minecraft 26.1.2 Fabric profile, start, and try /kp gui.
Right Shift = GUI, F9 = toggle, F8 = emergency stop.
Stand in Kuudra delivery center and /kp center. /kp arm inside Kuudra. Open GUI, enable fishing and optionally pearl delivery, configure hotbar slots. /kp start.
Supports manual /kp lock to crosshair and /kp picked or /kp delivered if server messages aren't detected.

Automation has a ban risk on Hypixel; using vanilla inputs does NOT make it allowed. Never run unattended.
